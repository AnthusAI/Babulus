================================================================================
KEY TECHNICAL SOLUTION
================================================================================

The critical insight: Amplify Gen 2 v1.20.0 uses AmplifyDynamoDbTableWrapper
which requires accessing tables through cfnResources.amplifyDynamoDbTables:

  const amplifyJobTable = backend.data.resources.cfnResources.amplifyDynamoDbTables['Job'];
  amplifyJobTable.streamSpecification = {
    streamViewType: dynamodb.StreamViewType.NEW_AND_OLD_IMAGES,
  };

This differs from Plexus (v1.8.0) which uses table.node.defaultChild.
